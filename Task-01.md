Task 1: Django Project Setup & MySQL Configuration

Objective

Initialize a new Django project using the latest version (Django 6.0+) and configure it to connect with a MySQL database.

Requirements

Django Initialization:

Create a new Django project and a dedicated app for the parking system.

Follow standard project structure and best practices.

MySQL Database Configuration (settings.py):

Configure Django to connect to a MySQL database using mysqlclient or pymysql.

Use environment variables (.env file via python-dotenv) for database configuration (DB_NAME, DB_USER, DB_PASSWORD, DB_HOST, DB_PORT).

Deliverables:

Complete project configuration ready for model migration.
